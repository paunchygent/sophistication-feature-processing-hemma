Sophistication Feature Processing on Hemma

This is a general research workstation. It is not restricted to a workshop.

HOME
  Hemma Home opens /home/paunchygent from inside the container at /hemma-home.
  File pickers start there.

TOOLS
  TAALED runs lexical-diversity analysis in a detached worker.
  TAALES opens its upstream interface plus a card with copyable paths.
  JASP is a known runtime gap: Flatpak/Bubblewrap cannot create its namespaces
  inside the current Docker/Webtop layer. The launcher reports this explicitly.

DATA SHORTCUTS
  ELLIPSE train and test, the private HuleEdu cohort, and workshop texts appear
  under Data and results when those directories are installed. They are optional
  conveniences; choose any suitable flat directory of lowercase .txt files.

RESULTS
  Save under Hemma Home or the durable service workspace. TAALED creates a new
  run directory and only publishes it as complete after checking the CSV rows.
  A .incomplete directory records an interrupted or failed run.

REMOTE DESKTOP
  LXQt provides the panel, desktop, and PCManFM-Qt file manager; Openbox manages
  windows. Scott's portrait is the canary that this desktop loaded. This stack
  replaces the incompatible XFCE/Glycin session. There is no recovery watchdog.
  If the web page is disconnected, reload it; the container-side
  TAALED worker continues unless the container itself is restarted.
